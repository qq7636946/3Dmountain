## FOUR PATHS → 卡牌

- 旅程停在 FOUR PATHS ONE VISION，原本後面的 PRE-IPO 等四章拿掉。
- 繼續往下捲（或按章節按鈕、右下的 VIEW PORTFOLIO）：鏡頭往前往下滑，河流的光加速、變亮、繼續流，山谷的空氣變濃成藍灰霧，卡牌從霧的深處一張張飛進來；往回捲會退回山景。

## 建置（維護）

index1-5 的程式是建置產生的，不要直接改 `prototypes/index1-5/js/`。執行：`node prototypes/index1-5/build.cjs`

- `cards-bridge-build.cjs`：旅程終點、轉場、卡牌導覽、轉場參數。
- `alpine-team-build.cjs`：把 `prototypes/index1-5/alpine/` 的打光、山形材質、介面套進來，並加上兩組參數。來源模組與修改腳本都在 `alpine/`。
- 三位組員的工作區是 `index1-5-alpine.html`／`prototypes/index1-5-alpine/`，保留作參考。

## 驗證

- 桌機 1440×900：開場、LOGO、峽谷、升起、空拍、FOUR PATHS 8 個位置；手機 390×844：5 個位置；FOUR PATHS → 卡牌用真實滾輪錄 8 秒；往下進卡牌、往上退回、按鈕進卡牌都通過；參數面板三組都有出現；主控台 0 錯誤。
- 載入：頁面可操作約 4.7 秒，山景準備好約 7.0 秒（地形建置多了侵蝕，約 +1 秒）。地形三角形 455,868 → 559,300；整個畫面約 244 萬三角形。這台開發機一直維持 120 fps 上限，所以**沒有量到真正的 GPU 差異**；沒有做實機手機測試。

## 已知與授權

- 峽谷升起時，河岸邊有一些鋸齒狀的岸緣，是原本河岸模型造成的。遠方靠近地平線的山有一點縱向條紋。少數高峰仍偏平滑的金字塔形，把「起伏」調高會更崎嶇，但尖刺也會變多。
- 侵蝕細節來源：「Snowy Mountain V2 - Terrain」by artfromheath（Sketchfab，CC BY 4.0），上線時要在網站列出署名。
- 介面：Windows 沒有內建很細的 Didone 字型，標題用 Sitka Banner 等本機字型，沒有新增外部字型下載。
