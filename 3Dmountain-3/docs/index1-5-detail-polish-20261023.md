# index1-5：細岩、分枝山脊與負載收斂（2026-10-23）

客戶允許進一步發揮視覺創意、加強材質與山形，但要求注意效能。入口仍為 `index1-5.html`，本次所有程式修改都在 `prototypes/index1-5/`，共享原始碼及其他版本沒有更動。

## 視覺

- 以主山脊與向下分叉的支脈整理峰體；中近景保留較清楚的稜線，僅在粗網格遠山收斂尖針。保持原河道和鏡頭；水邊65單位內的河岸高度不變，上層階梯調整限制在2.5單位。
- 冷灰藍岩面、暖灰褐碎坡、斜向侵蝕細縫及小尺度礦粒；中景仍保留可見的照片細節。取樣按距離、世界座標的螢幕像素大小連續淡出，遠處保留主山勢與地質色塊。
- 雪斑及氣候擾動使用XZ座標，不用高度週期形成繞山條帶；近岸石塊略過整段雪計算。保留小岩石及礦粒的高光抗鋸齒。
- 雲的外形隨風略微變化，邊緣有柔光與冷暖層次。從既有密度求光向梯度，省去第二次完整密度計算；仍19組雲（手機11）、一次instanced draw。額外薄霧絲因實景讀成水平亮線而移除。
- 全畫面顆粒由.010收為.006，避免細節被粗顆粒蓋住。
