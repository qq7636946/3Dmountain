# index1-5 第二章螺旋水滴：不再是一排印出來的珍珠（2026-10-24，視覺總監）

客戶：「這螺旋水滴很怪，可能太規則或是怎樣」。
圖：[改前／改後、近看、真實滾輪、手機、減少動態](index1-5-opening-world/drops-before-after-20261024.jpg)。

## 為什麼怪
- **每顆都一樣**：每顆水滴都是同一面鏡子，照著同一個無限遠的房間，所以頂上的窗光圈、中間的白光帶、暗下半部每顆都一模一樣，看起來像印出來的。
- **太規則**：主串大小差異只有 .18，幾乎一樣大。客戶預設把螺旋的起伏（wave）設成 0，所以排成一條乾淨的弧線。
- **沒有遠近感**：近的遠的一樣清楚、一樣亮。

## 改了什麼
- **質感**（`opening-drops-build.cjs`，只作用在字母章的螺旋）：
  - **金屬比例每顆不同**：平均 .42、每顆再差 ±.26；大顆比較像英雄水珠的鏡面，小顆比較像清水。
  - **倒影各自轉一點**：每顆倒映的房間轉不同的角度，光帶和窗光不再對齊。
  - **透出背後的世界**：折射裡是開場真實的天、太陽、遠山，所以在太陽前的水滴裡有倒過來的太陽，在山前的有山。
  - **太陽**：太陽那側一條暖色邊光，再加一個跟著水滴位置移動的亮點。
  - **遠近**：比字標近的水滴失焦（反光變柔、邊緣變軟），比字標遠的沉進空氣（霧化 .2 → .4）。
  - **窗光高光**：棚燈窗光 .66 → .2。
- **大小與位置**（`letters-entrance-build.cjs` 的水滴部分）：
  - 主串大小差異 .18 → 1，每顆再隨機 ±28%，約兩成是加大 50% 的特大水滴。
  - 每顆偏離螺旋線（前後、上下都有，所以遠近也拉開），並在原地慢慢漂移（減少動態模式下不漂）。
  - 數值都綁在每顆水滴的種子上，同一顆水滴每次都一樣。
- **編排沒動**：水滴先轉、讓出中間、文字出海成字，時間都沒動。客戶預設、字母特效、logo-look 也都沒動。

## 參數
- **「水滴 · 數量與大小」新增**：每顆大小隨機、特大水滴比例、特大水滴加大、位置離開螺旋、原地漂移。
- **新組「水滴 · 質感（螺旋）」**：金屬比例（平均、每顆差異）、倒影每顆轉向、太陽暖邊、太陽亮點、近處失焦、遠處沉入空氣、透出真實世界。

## 客戶預設（沒有改，建議）
`presets/user-20261023.diff.json` 最後才套用。下面這幾項在字母章仍然有作用，也是「太規則」的一部分：

| 參數 | 現在 | 建議 | 作用 |
|---|---|---|---|
| `wave` | 0 | .035 | 螺旋本身的起伏 |
| `stretch` | 0 | .25 | 水滴順著運動方向微微拉長 |
| `wobble` | 0 | .012 | 表面微動 |
| `wobbleSpeed` | 0 | .5 | 表面微動的速度 |
