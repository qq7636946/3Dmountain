# index1-5：最後一段 3D LOGO 的專用數值 bar（2026-10-24）

客戶：「最後一cut的3D LOGO 要開數值bar給我」。
附圖：[位置與旋轉](index1-5-logo-panel/panel-position-20261024.jpg)、[玻璃光學](index1-5-logo-panel/panel-optics-20261024.jpg)。

## 先量到的事
- 這組參數其實早就有：tuner（`T`）裡的「LOGO 收尾 Logo Seal」，約 130 條，最後一段也看得到、調得動。
- 問題是它被擠在 64 組的最底下，上面堆著引導光束、亮光點、全站太陽等新組，要一路往下翻。
- 所以不是「沒有」，是「找不到、又太多」。這次做的是**只放 3D LOGO 的專用小面板**，就在最後一段旁邊。

## 怎麼用
- **按 `M` 開關**。在 localhost 上，捲到最後一段（LOGO 收尾）時**會自己打開**；按 × 關掉後，離開這一段再回來才會再自動開。
- 面板最上面：**前往最後一段**（從頁面任何位置自動帶你到最後一段的停留畫面）、**看浪**、**看旋轉**、**看停留**。
- 拉 slider 或直接輸入數字，3D LOGO **即時**跟著變，不用重整。色彩列是色票加色碼。
- 滑鼠在面板上時滾輪只捲面板，頁面不會跟著動。
- **雙擊參數名稱**＝還原那一條。改過的條目有金色圓點，區段標題顯示「N 項已改」。
- 底下三顆：**複製參數**（只複製和預設不同的，JSON 格式）、**貼上參數**、**全部還原**。
- 改過的值自動存在這台瀏覽器（localStorage），重整後還在。**把「複製參數」的內容貼給我，就會變成新的預設值。**
- 只有 localhost（或網址加 `?logopanel=1`）才存在；正式網站的訪客看不到、也不會讀到你存的值。`?logopanel=0` 完全關掉。

## 內容（7 組、66 條）
| 區段 | 內容 |
|---|---|
| 位置、旋轉與升起（預設展開） | 符號高度／大小、大小倍率、上下位移、結尾停的角度、旋轉開始／長度／完成點／緩動、從水面升起開始／完成／緩動、停留長度、手機的高度與大小 |
| 形體 | 整體大小、厚度、水管圓度、圓角半徑、圓角柔化、邊緣曲線、圓角段數、正面隆起 |
| 玻璃光學（預設展開） | 透光、折射厚度、折射率、色散、底色、吸收色與距離、霧面、清漆、鏡面、環境反光、環境旋轉、雙面折射 |
| 表面與邊緣光 | 絨光、虹彩、柔邊光強度與寬度、邊緣亮線、邊緣光色 |
| 水感 | 內部散射光、焦散（強度、細緻度、流速）、折射流動 |
| 品牌藍（上方葉片） | 量、亮端與深端色、內部藍光、吸收距離 |
| 打光與倒影 | 玻璃的太陽光與天光填充、環境反射、符號倒影（強度、長度、漣漪、菲涅耳、模糊） |

「從水面升起」那三條，原本在大 tuner 裡沒有列；現在大 tuner 和這個面板都有。

## 怎麼做的
- 新檔 `prototypes/index1-5/logo-panel.js`（面板）與 `logo-panel-build.cjs`（小幫手，已在 `build.cjs` 清單裡，接在 `world-daylight-off-build.cjs` 後面）。
- 列表在建置時直接從上線的模組讀（`world-logo-mark.js` 的 `MARK_ROWS`、`world-logo-scene.js` 的 `LAKE_ROWS`、`world-logo-build.cjs` 的 `SEAL_ROWS`）。別人新增、改名的參數，下次建置自動跟上；CONFIG 裡不存在的 key 會直接略過。
- 值直接寫進 `CONFIG.logoSeal／logoMark／logoLake`，和大 tuner 同一份，世界每一幀都在讀。大 tuner 動到同一條時，面板的數字會同步。
- 沒有改任何預設值、造型、時間點，只多了面板。共用的 `js/` 完全沒動。

## 驗證（真實 GPU Chrome）
- `M` 開關；按「前往最後一段」從頁首自動帶到停留畫面（約 6 秒）；面板自動開。
- 拉 4 條（厚度、折射厚度、吸收色、停的角度）：CONFIG 跟著變、3D LOGO 變藍變薄且轉了角度（畫面差異約 6%）；雙擊還原一條；重整後值還在；全部還原後儲存清空。頁面錯誤 0。

## 這次沒有一起上線的東西
這次只把面板補進產出（`node prototypes/index1-5/logo-panel-build.cjs --sync`，只動 `js/main.js` 與 `js/logo-panel.js`）。當時別的 session 對 `world-logo-mark.js`、`world-logo-scene.js`、地形材質、傳送門的來源都有還沒建置的修改，不屬於這次的工作，所以沒有整套重建。之後有人用 `build.cjs` 重建時，面板會依清單一起帶上，結果相同。

## 還原
- 整個拿掉：從 `build.cjs` 清單刪掉 `'logo-panel-build.cjs'`，重建；或網址加 `?logopanel=0`。
