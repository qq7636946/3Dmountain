## 現況（與新規格有關的部分）

- 字母現在是「冰」：在水滴著色器裡光線步進出來的冰字（`ICE_GLSL`，切邊＋霜），放手後換成擠出玻璃的字標網格。→ 新規格禁止冰與硬玻璃，**字的材質與做法要換**。
- 水滴與字母綁在一起（11 顆水滴各裝一個字母）。→ 新規格要分開；水滴可沿用現有的「清水水滴」畫法與螺旋（`water-logo-drops.js`）。
- 章節結尾必須有完整字標：下一章「穿過字標往前衝」的轉場用它。→ 新規格要求最後水滴與字**離開焦點**，與此衝突（見「需要您決定」）。
- 捲動：網站自己的章節時鐘（捲動＋彈簧慣性，可倒轉），不是 GSAP ScrollTrigger。

## 材質：液態果凍字

| 要求 | 做法 |
|---|---|
| 圓潤、柔和邊緣、無切面 | 字標原本的字形輪廓，擠出時用 6 段圓角倒角（往內收 1.3、圓角 2.1、厚 3.2，單位為字標座標），正面像倒出來的果凍般鼓起；沒有切邊與霜 |
| 濕潤鏡面、高光隨旋轉移動 | 物理材質：透光 1、折射率 1.36、粗糙度 0.04、清漆層 1、環境光反射；輕微色散與邊緣柔光 |
| 適度半透明、輪廓清楚 | 體積吸收（淡藍，越厚越藍、薄邊透明），背景與後方物體透得過去；不霧化、不乳白 |
| Q 彈、受力形變與回彈 | 頂點著色器：字隨加速度產生慣性偏移（遠端落後），由**欠阻尼彈簧**帶回（約 1.9 Hz、晃兩下停住）；加速或轉動時累積晃動能量，做衰減的壓扁—拉長；振幅上限 9%，字不變形到難讀 |
| 不增加大量面數 | 每字約 6–7 千個三角形（全部約 7 萬）；形變全在 GPU 做，沒有物理模擬網格 |

## 動態：兩組獨立物件、兩條錯開的螺旋

章節進度 0–1（可正向、反向、隨捲動）：

| 階段 | 進度 | 水滴 | 字母 |
|---|---|---|---|
| ① 起始 | 0 起 | **先起動**：各自旋轉（各自的旋轉軸與轉速，小的轉得快）、沿螺旋上升 | 單字完整可讀，果凍輕輕晃 |
| ② 字距拉開 | 0.14–0.40 | 持續上升 | 字距逐漸拉開（桌機到 1.55 倍、窄螢幕較少），每個字母開始各自 3D 轉動 |
| ③ 螺旋上升 | 0.30 起，每字間隔 0.028（F 先） | 前排、後排兩條扁螺旋：從字的前方或後方經過，**永不穿過字** | 沿另一條**偏移的中心軸**螺旋上升；各自的相位、轉速、深度、間距；轉動以左右擺為主，字面不斷轉回觀眾，保持可讀 |
| ④ 離開焦點 | 0.80–1.0 | 加速上升出畫面 | 上升、往深處退、略縮小，留出畫面給下一段 |

- 時間差：水滴從 0 開始動，字母 0.14 才開始變化、0.30 才離開原位；兩組速度與方向都不同步。
- 前後層次：約三分之一的水滴走後排（字的後方），其餘走前排（字的前方）；前排水滴會折射出後面的果凍字。
- 標題與 CTA：所有物件都在標題上方運動，全程清楚。
