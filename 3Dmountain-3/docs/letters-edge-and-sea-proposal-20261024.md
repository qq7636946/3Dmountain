## 2. 現況（已核對程式與行號）

### 2.1 字母邊緣：它是怎麼算出來的

- 著色器：`js/water-logo-letters.js`（index1-5 另有一份生成的副本：`prototypes/index1-5/js/water-logo-letters.js`）。
- 邊緣法線：`iceCut(G, rim)`（:105–108）。`band = 1 − smoothstep(0, cut, rim)`，傾斜量 `G · band² · bevel`。也就是說傾斜在輪廓處最陡、用平方速度消失，看起來是「切出來的冰塊斜面」，不是圓角。
- 邊緣亮光：三段疊加。`edge`（:123，牆與面之間的轉折，接近白色）、`line`（:180–181，沿輪廓的細亮線，寬度 `cut·0.42`）、`inner`（:182–183，切邊內側的暗階，會形成一道台階感）。這三段讓邊緣顯得銳利。
- 預設值（`LOGO_LETTER_DEFAULTS`，`js/water-logo-letters.js:46`）：`cut .05`、`bevel 1.15`、`bend 1.14`、`clear .5`、`needles 1.1`、`sparkle .65`、`tone .93`、`rimLight 1`；`locked .36`、`fused 0`。
- 數值進入頁面的地方：`js/main.js:428` 的 `logoLetters: { ...LOGO_LETTER_DEFAULTS, ... }`（`risingLetters` 只改 `directedHelix`、`overshoot` 等動態參數，不改邊緣）。
- 調整面板（中文標籤，`js/main.js:7051–7063`）：切邊寬度（cut，0.01–0.1）、切邊斜度（bevel，0–2.5）、結霜量（frost，0–1）、霜針紋理（needles，0–1.5）、冰晶閃點（sparkle，0–1.5）、輪廓亮線（rimLight，0–1.5）、折射彎曲（bend，1–1.5）、通透度（clear，0–1）、霜面明度（tone，0.5–1.2）、冰字邊線（iceEdge，0–1）。
- 字母是 opt-in：網址帶 `?letters=1`，或在頁面按 L 才載入（`js/main.js:7758–7760`）。

## 3. 方案與風險

### 3.1 字母邊緣

- **方案 A：只調參數（不改程式，風險低，可立刻試）。** 建議起點：切邊寬度 `cut` .05 → .09；切邊斜度 `bevel` 1.15 → .6；輪廓亮線 `rimLight` 1 → .4；霜針 `needles` 1.1 → .4；冰晶 `sparkle` .65 → .2；結霜量 `frost` 降低；折射 `bend` 1.14 → 1.25（水約 1.33，越高越像水）。用面板即時調，滿意後「複製參數」交給工程師寫成預設。
- **方案 B：改成真正的圓角剖面（改程式，風險中）。** 把 `iceCut` 的 `band²` 換成圓弧剖面（傾斜隨距離線性變化，邊緣處趨近水平），並把 `line` 與 `inner` 改成柔和的漸層，不留銳利的台階。新增一個「圓角」旋鈕（0＝原本的切冰斜面，1＝圓角），保留舊的樣子。
- **方案 C：水感（改程式加動態，風險高，動態需另外核准）。** 邊緣改用水面的細小起伏取代霜面，加上隨時間流動的細紋，讓光在邊緣跑動。

建議先做 A；A 試過仍不夠圓，再做 B；C 需要你另外點頭，因為會加動態。

### 3.2 圖一、圖二帶過來

### 3.3 俯視海島

- **方案 I：保留現有鏡頭，在山谷外圍加一圈海。** 用 `world-ocean` 的海面，加上貼合山谷輪廓的岸線遮罩。不動鏡頭，風險中（要處理岸線與山谷的銜接）。

- **方案 III：靜態合成圖。** 做成一張俯視的島嶼合成圖，風險低但缺乏動態，與山谷的光線與深度不一致。

## 8. 方案 B 已套用（2026-10-24，你選的「做方案 B」）

改了著色器的邊緣剖面，並新增一個「圓角剖面」參數（`round`，預設 1）。

- 剖面：`iceCut` 原本是 `band²`（陡、像切冰斜面）。新的剖面是 `cos(90°·t)`，t 從輪廓（0）到平面（1），像圓角的轉折。`round` 0 會回到舊的 `band²`。
- 亮線：`line` 的寬度隨 `round` 變寬（`cut·0.42` → `cut·0.9`），比較柔。
- 暗階：`inner` 的台階在 `round` 1 時消失。
- 新參數的位置：`js/water-logo-letters.js`、`prototypes/highland-1-4-ascent/js/water-logo-letters.js`（預設 `round: 1`、著色器 `uIceRound`）、`js/main.js` 的調整列（`圓角剖面`，0–1）、`js/water-logo-letters-panel.js`（L 鍵面板，同一列）。
- 快取版本：`js/main.js` 的 `water-logo-letters.js?v=…20261024b`、面板 `?v=…20261024b`。index1-5 用 `build.cjs` 重建，差異只有字母模組與兩個版本號。
- 備份：`_archive/backups/letters-edge-planB-20261024/`。
