## 第一階段：現況檢查

| 項目 | 現況（index1-3） | 與 Mont-Fort 的差距 |
|---|---|---|
| 山體模型 | 程式生成的峽谷岩壁、空拍山群、LOGO 環山、遠山；幾何、稜線、沖蝕溝、岩層都已有 | 幾何本身足夠，**不需要動** |
| 山體材質 | `MeshStandardMaterial`（粗糙度 .94），頂點色是藍灰（`#526676`→`#a0acb4`）；空拍時整片換成單一色調（`watershedStyle.rockColor`）；霜、雪是淡藍白；**沒有植被** | 這就是「冰塊感」的來源：色相只有藍灰，沒有暖赭岩、沒有暗綠植被 |
| 光源 | 天光 `#dce9f4`、太陽 `#ffead0`（逆光）、藍色邊光；環境光（IBL）來自開場那個淡藍「房間」，整個峽谷都被它照亮 | 藍色環境光把岩石洗成淡藍、明暗層次變平 |
| 天空、霧 | 峽谷天空 `#779abf`→`#d4dee5`、霧 `#b5c7d7`；空拍時換成「冰」色盤 | 偏冷藍，Mont-Fort 是陰天的暖灰白 |
| 水面 | 河流和開場海面共用同一個**鉻金屬**著色器（金屬 Fresnel，反射開場房間），所以是銀白、牛奶色；空拍時是平平的灰藍；岸邊浪花在空拍幾乎消失 | 不像水：沒有深藍水體、沒有天空倒影的漸層 |
| 後製、介面 | Neutral 色調映射＋bloom；CSS 的 `.fi-veil` 在畫面下半疊了約 55% 的白 | 白霧把深色水面洗成灰白；深色字只適合淺色畫面 |
| 鏡頭、捲動、轉場 | journey 進度 0–16.69：開場 → 字母 → 峽谷第一人稱（約 4.9–9.3）→ 鏡頭拉升 → 空拍（約 11 起） | **全部保留，不動** |

## 第二階段：改善方案（已在測試版實作）

量測的目標色（Mont-Fort 首屏截圖取樣，sRGB）：

| 區域 | 參考色 | 區域 | 參考色 |
|---|---|---|---|
| 天空頂 | `#8996a3` | 受光岩面 | `#928476` |
| 雲帶 | `#dee0d9` | 岩石陰影 | `#54524f` |
| 地平線霧 | `#abafab` | 山腰植被 | `#403e37` |
| 遠山霧化 | `#bdbeb7` | 海：地平線→中景→近景 | `#7e8f9a`→`#223d56`→`#0b253d` |
| 岸邊浪花 | `#c3cfd4` | 海中礁石 | `#3a3b3e` |

| 項目 | 做法 |
|---|---|
| 岩石材質 | 色相改由自然色盤決定（暖灰褐岩 `#8c7f70`、冷灰岩、赭色岩紋），原本烘焙在頂點裡的明暗（溝、縫、稜谷）只保留亮度，所以立體層次不變；赭色沿陡壁的沖蝕溝往下流（Mont-Fort 那種一道道暖色岩紋）；粗糙度維持 .94，不會有塑膠感 |
| 植被 | 新增：緩坡、植被線以下、水線以上的地面長暗橄欖色灌叢（`#3b4031`），用雜訊切成一塊一塊，不是整片塗色 |
| 雪、霜 | Mont-Fort 沒有雪：高山積雪關掉（`relief.snow` 0），稜線霜改成淡色風化岩（`#b2aa9c`），量也降低 |
| 濕岩帶 | 水線上方的濕岩改成中性深灰（原本偏藍） |
| 光影 | 陰天的單一光照貫穿峽谷與空拍：暖白日光加強、天光（環境補光）減弱、藍色房間的環境光降到 .35，岩石才有受光面與陰影面的重量感 |
| 天空、霧 | 陰天天空 `#8e9aa5`→`#d3d5ce`；霧是暖灰 `#c2c4be`，遠山一層層淡進霧裡（原本的遠景霧化、山谷霧、層次霧全部保留，只換顏色） |
| 水面 | 從鉻金屬改成水：水的 Fresnel（F0 .02）、深藍水體（近處俯看最深，掠射角稍亮）、天空倒影（河流倒映峽谷自己的天空，開場倒映陰天房間）、兩層隨風飄的細紋（依像素足跡淡出，遠處不會閃）、柔和的日光閃點；粗糙處反射變平，避免鏡面感 |
| 山海交界 | 沿用原本岸線的浪花蕾絲與岩石側的浪沫帶，改成白色；空拍時保留一部分，岸線看得到白浪 |
| 空拍河流與湖 | 原本的空拍水色換成深藍＋陰天天光反射；河流光束保留，亮度降到 .65 |
| 介面配色 | 峽谷與空拍時：文字改白、毛玻璃改煙灰、下方的白霧改成淡淡的深藍陰影（深字在深藍水面上讀不到）。開場維持原本的深字 |
| 調色 | 整頁色調略暖（temp +.06），彩度 .97 |

## 需要您決定（整合到正式網站之前）

1. **開場（hero）**：測試版把開場的「淡藍房間」換成陰天天空、海面換成水（玻璃水滴不變）。要保留原本的鉻金屬海面嗎？（參數「開場海面也是水」設 0 即可預覽）
2. **介面配色**：峽谷與空拍時改白字＋煙灰玻璃，可以嗎？這會改到介面的顏色（不動版面）。
3. **雪**：要完全不要雪（像 Mont-Fort），還是保留高處少量積雪？
4. **河流光束**：維持降亮（.65）、恢復原亮度，或關掉？
5. **整合範圍**：`js/main.js` 是 index.html、index1-1、index1-2、index1-3 共用的。建議只在 index1-3 加 `<html data-look="maritime">` 開啟，其他頁完全不變；或您想全部頁面一起換？
6. **效能**：岩石每個像素多 4 次雜訊取樣、近處水面多 6 次，預期影響不大，但正式整合前要在手機與目標裝置實測一次。
