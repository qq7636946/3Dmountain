# index1-4 · Highland（2026-10-22）

`index1-4.html` = index1-1 的整頁旅程，**山景換成 Blender 延伸的高地世界**（`../highland-world-20261022/`），材質照定稿圖，並依客戶要求：**綠色草皮少 50%**、**天空更亮**、**水滴改成同風格**。
**正式網站與其他頁沒有任何改動**：index.html／index1-1／1-2／1-3／index2 與 `js/`、`css/` 全部檔案的 SHA-256 與動工前一致（`shared-before.sha256`，`sha256sum -c` 35／35 OK）。

開啟：`http://localhost:5178/index1-4`（本機開發伺服器；調整面板 C／L 在 localhost 自動開，設定與 index1-1 分開存）。
**陽光版是預設**；`http://localhost:5178/index1-4?look=overcast` 可切回先前核可的陰天版（山景、開場房間色、整頁色調、玻璃 UI、泛光、頁面 CSS 全部一起切回），方便對照，也是復原方案。

## 2026-10-22 第三輪：開場水滴與海、草更少、岩石層次、藍色光線（參考 index1-3-maritime）

- **開場（01 KNOWLEDGE、02 INNOVATION）融入山景**：開場房間改成晴空（頭頂藍、地平線亮霧、下方深青綠海），地平線上有一道遠山（山頂清楚、山腳溶進水面上的霧）。背景畫它、海面倒映它、水滴反射它（同一個方向函式 montisEnv）。開場海面從「金屬」改成「水」：照 index1-3-maritime 的作法，介電質菲涅耳＋深青綠水體＋房間倒影＋太陽反光。水滴的暗面旗從深藍改成深海青、光色略暖、彩虹膜減少。海平線略往上，水面多一點。全部在 `build.cjs`，只在陽光版生效。
- **草地再少**：草地佔畫面中地面的比例由約 20% 降到約 12%（`LOOKS.sunny.grassCut .25`，實測：島 10%、谷地 13%、空拍 13–14%）。
- **岩石顏色層次**：每一層岩層從較寬的天然色盤取自己的顏色（赭、鐵鏽、石灰白、褐、藍灰、灰黃），亮度也各自不同；細層冷暖交錯；整座山體偏暖或偏冷。強度 `layers .55`（`highland-material.js`）。
- **光線改藍色**（客戶：第一人稱光線要藍色的 不要橘色光）：白熱核心＋冰藍光暈（`ice`），第一人稱與四條河都是藍色；陰天版保留原本的金色。
- **河水**：水體加深（`water 0x2f7891`），去掉 Water.js 把水面洗白的太陽漫射（.3 → .07），從空中看是深一點的藍，不再是奶白。
- 效能不變（開場 1.3 ms、峽谷 3.6 ms、空拍 4.5 ms／幀）。審查圖：`renders/round3-before-after.jpg`、`journey-sunny-desktop.jpg`、`journey-sunny-phone.jpg`。

## 改了什麼、在哪裡

- `build.cjs`：**唯一的建置入口**。把 `js/main.js`、`water-logo-drops.js`、`water-logo-letters-panel.js`、`finnovation-grade-panel.js` 複製到 `js/`，以「錨點必須剛好出現 N 次」的方式修改，其餘 import 全部指回共用的 `../../../js/`（與 index1-1 同一個檔案、同一個 `?v=`），並把 index1-4.html 指向這份副本、加 `data-look="highland"`、`noindex`。**不要手改 `js/main.js` 等副本，改完重跑** `node prototypes/highland-1-4/build.cjs`。
- `js/highland-scene.js`：取代 index1-1 的程序峽谷（同樣的物件介面）。天空 ×1.25、霧色等於天空地平線色（不會出現硬接線）、Water.js 銀色海面＋岸邊白沫、依章節進度 q 的鏡頭路線（單調三次插值，速度不跳）、防止鏡頭進山。
- `js/highland-terrain-worker.js`：在背景執行緒把高度場轉成有岩層刻劃的地形（定稿圖的 strataAt／階梯／岩脊），飛行路線與島為 2.34 單位、越遠越疏，分塊加裙邊。桌機約 140 萬頂點、3 秒；手機（lite）約 40 萬頂點、1 秒，並改用 2.1 MB 的 1025² 高度圖。
- `js/highland-material.js`：定稿圖材質；`grassCut .18` = 草皮覆蓋量實測減半（近景 35%→約 17%、空拍 43%→約 22%、谷地 53%→約 26%）。
- `main.js` 副本的改動：地形來源、`CONFIG.field`（開場房間＝水滴倒影色）改高地陰天色、水滴與字母顏色、整頁色調改中性、高地場景時抑制泛光（否則亮天空整片發光變霧白）、調整面板各自的儲存鍵。
- `highland.css`：把共用的白色漸層罩淡化，標題與小字、左側章節列加淡淡的光暈／霧光底，讓深色字在岩石與霧上都看得清楚。
- `assets/`：`world-height-2049.dz`／`world-height-1025.dz`（壓縮高度圖，見上）、`world-meta.json`、`textures/`（Poly Haven CC0 岩壁／草地 2K＋1K、地形侵蝕法線、水面法線）。
