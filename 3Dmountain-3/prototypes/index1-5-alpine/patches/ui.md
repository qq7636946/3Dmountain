# ALPINE-UI — everest-style interface (index1-5-alpine → index1-5)

2026-10-23. Restyles the FINNOVATION interface after everest.suraj.work: Didone/thin-serif titles, gold kicker
phrase, gold pills, round glass icon buttons, gold progress hairline on the top edge, frosted stat bar with live
journey data, transient chapter emblem (outline Roman numeral + italic gold chapter name), a few in-scene labels.
Copy, chapters and buttons are unchanged; no firm facts or figures are added.

## Files

| file | what |
| --- | --- |
| `prototypes/index1-5-alpine/index1-5.css` | one block between `/* ==== ALPINE-UI START` and `/* ==== ALPINE-UI END ==== */` at the end of the file. Every rule is keyed on `html[data-alpine-ui]` (and `:not([data-render-mode="text"])` except the text-mode guards). Copy the block verbatim to the end of index1-5's stylesheet. |
| `prototypes/index1-5-alpine/alpine-ui.js` (new) | standalone ES module, no imports. Copy next to the page's other prototype files. |

The module only reads `window.__MONTIS_STUDY__` (`journey.progress/max`, `canyon.camera`, `canyon.watershed`
→ `descriptors`, `mainAt`, `terrainAt`, `stats.terrainRevision`) and the interface DOM (`[data-journey-ui]`,
`.fi-rail button[aria-current]`, `.fi-copy-panel`, `data-chapter`). It never writes to the scene. If
`__MONTIS_STUDY__` is renamed or made debug-only in index1-5, the stat bar shows "—" and the labels stay off;
nothing else breaks.

after
```html
<html lang="zh-Hant" prefix="og: https://ogp.me/ns#" data-letter-direction="rising-helix" data-epilogue="world" data-landscape="1010" data-look="index1-5" data-alpine-ui>
```
(only the trailing ` data-alpine-ui` is new; keep whatever other attributes index1-5 has.)

### 2. The module tag, directly after the journey module (never above the import map)

before
```html
  <script type="module" id="journeyModule" src="prototypes/index1-5-alpine/js/main.js?v=i15-mvkpf9fm" onerror="showFinnovationText()"></script>

```

```html
  <script type="module" id="journeyModule" src="prototypes/index1-5-alpine/js/main.js?v=i15-mvkpf9fm" onerror="showFinnovationText()"></script>
  <!-- ALPINE-UI: everest-style interface layer (stat bar, scene labels, chapter numerals); styles in index1-5.css -->

</body>
```
For index1-5 point `src` at its own copy (e.g. `prototypes/index1-5/alpine-ui.js`) and stamp `?v=` as the build does.

### 3. Cache-bust of the stylesheet link (version string only)

before
```html
  <link rel="stylesheet" href="prototypes/index1-5-alpine/index1-5.css?v=i15-mvkpf9fm">
```
after
```html
  <link rel="stylesheet" href="prototypes/index1-5-alpine/index1-5.css?v=i15-mvkpf9fm-alpui2">
```
(not needed in index1-5 if its build stamps the CSS hash itself.)

No other markup is touched. Everything else the layer adds is created at runtime by `alpine-ui.js`
(so it also works on HTML regenerated by `scripts/seo/build-static-interface.mjs`):

| runtime node | where | a11y |
| --- | --- | --- |
| `<span class="alp-gold">` around the last ` · ` phrase of each `.fi-copy-kicker`; `<span class="alp-num">` around the `01` of `01 / AI 量化交易` | inside the kicker, same text | text unchanged |
| `<span class="alp-or">or scroll</span>` after the opening button | `#chapter-knowledge` | aria-hidden |
| `<p class="alp-mark" lang="en">Innovation</p>` (chapter name, italic gold) after each h2 | panels 2–10 | aria-hidden (the rail names the chapter) |
| `<div class="alp-emblem">` numeral + name, animated on chapter arrival (III–VI; not on the opening frame or the logo chapter, whose letters own the centre) | `.finnovation-ui` | aria-hidden |
| `<aside class="alp-stats" aria-label="旅程資訊 Journey"><dl>…` | `.finnovation-ui` | real text, not live-announced |
| `<div class="alp-labels">` with `.alp-pin` labels | end of `<body>` | aria-hidden, pointer-events none |

The block also fixes one pre-existing text-mode glitch (keyed on `html[data-alpine-ui][data-render-mode="text"]`):
if the 3D page had reached the canyon before falling back, the shared `[data-scene="canyon"] .fi-header` rule left
a white logo/nav on the light readable page; the header now keeps the dark ink.

Contrast: small tracked caps sit over snow and water, so the layer adds a navy veil band along the top and the left
(header, rail), a soft dark ellipse behind the active copy (`.fi-copy-panel::before`), a tight text halo, and a
lighter gold (`--alp-gold-hi`) for small gold text. Measured with the scene behind each text run (p90 luminance,
halo included) at p 0/8.9/13.36/15 desktop and 0/8.9/13.36 phone: everything ≥ 4.5:1 except an occasional rail
item over a sunlit canyon wall (≈4.4:1).

`html[data-alpine-ui-live]` is set while the stat bar exists (hides the footer's own `KNOWLEDGE … 01 / 06` text,
which the stat bar replaces). The text mode (`showFinnovationText()` / `finnovation:text-mode`) removes the stat
bar, labels and emblem, and CSS hides the marks.

## Stat bar (honest data only)

| cell | source |
| --- | --- |
| VIEW HEIGHT | `canyon.camera.position.y`, scene units, no unit claimed |
| HEADING | bearing of the camera's view direction, degrees + 8-point compass (−z = N) |
| JOURNEY % | `journey.progress / journey.max` |
| TAIPEI TIME | `Intl` time in Asia/Taipei (the page itself says the firm is rooted in Taipei) |
| CHAPTER | index of the rail button with `aria-current` + `/06` |

Phones show VIEW HEIGHT, JOURNEY %, CHAPTER between the round sound and next buttons; ≤1100 px drops HEADING.

## Scene labels

Only once the camera is above ~450 scene units (the watershed views), never over the copy, header, rail, footer,
stat bar or emblem (tested against the actual text runs), and never when a ridge hides the anchor (line-of-sight
marched over `terrainAt`).

- `CONFLUENCE / 匯流` — on the main river at the mean `joinZ` of the four tributaries.
- `SUMMIT / 頂峰 · ▲ <height>` — highest baked terrain point in x ±2600, z −5200…−3400; the number is that
  point's height in scene units; recomputed when `stats.terrainRevision` changes.
- Station tags `I AI QUANT TRADING` … `IV DERIVATIVE STRATEGIES` (text read from the four business panels' h2) on
  the four tributaries, only in the STRATEGIES chapter; the current sub-panel's tag is highlighted. They walk
  along their river and switch side to stay clear.
- Phones: tags hidden; confluence and summit only when they fit.

## Dials

- `?uiserif=sitka|bodoni|didot` — force the display face (A/B).
- `?alpui=0` — turn the whole layer off (removes `data-alpine-ui` before anything renders).

## Fonts (local only — no new requests)

- Display: `Didot, "Bodoni 72", "Sitka Banner", "Bodoni MT", "Noto Serif Display", "Noto Serif", Georgia, serif`
  → Apple devices get Didot; every Windows 8.1+ gets Sitka Banner (thin, high-contrast display cut); Bodoni MT
  (Office) was tried first but is too heavy for the "thin" look and too wide for the one-line opening title.
- Numerals: `Bahnschrift` at `font-stretch: 75%` (Windows) → `Avenir Next Condensed` (Apple) → Arial Narrow → Jost.
- Small caps / mono: Jost (already loaded) and `ui-monospace, SF Mono, Cascadia Mono, Menlo, Consolas`.
