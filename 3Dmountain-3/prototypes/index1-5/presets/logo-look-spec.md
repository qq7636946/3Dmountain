# 3D LOGO 本體視覺規格：冰河融水，山谷的光（2026-10-23，視覺總監）

客戶定調：「山谷那段為主」。第一、二塊的房間正在換成山谷那片天、那顆太陽（`opening-world-build.cjs`）。
字標本體（液態字＋LOGO 玻璃）要像**同一個山谷裡的冰河融水／冰**，而不是棚景裡的霜白塑膠。
特效（成字、水珠、散開）不動；這份只管本體的顏色、光、材質感。由 `logo-look-build.cjs` 實作。

## 一句話
清透的融水冰：厚的地方是深藍的芯，表面映著鈷藍天的一道光帶，朝太陽那側有一條暖金邊光，背光側是冷藍陰影；F 那一撇維持品牌藍。

## 色票（sRGB，畫面上看到的值）
| 角色 | 色 | 說明 |
|---|---|---|
| 深芯 core / absorption | `#0f3a6e` | 厚處（字腹、筆畫交會）吸收後的顏色；Beer–Lambert 往這裡走，不是往灰或黑 |
| 本體 body | `#2c6aa6` | 中等厚度透出來的融水藍 |
| 清面 clear face | `#e3eef9` | 面向鏡頭的薄處：幾乎透明，微帶冷藍；**不要** `#f4f8fe` 那種霜白 |
| 天空反射帶 sky band | `#3b74b9` → `#cbd8e6` | 上緣映鈷藍天，往下過渡到地平線霧色（＝山谷 skyMid → skyHorizon） |
| 霧 haze | `#c4d3e4` | 遠側／折射到的空氣 |
| 暖金邊光 rim | `#ffc690` | 太陽側的輪廓光（＝山谷 rimColor） |
| 太陽高光 spec | `#ffdcb8` | 小而燙的針點高光（＝山谷 sunColor），只在太陽側 |
| 冷陰影 shade | `#1b3352` | 背光側與內壁；**冷藍，不是灰** |
| 墨 ink | `#13233c` | 最暗的折邊線（＝開場房間 ink） |
| 湖面反光 bounce | `#4d7f8c` | 從下方湖面（冰河湖灰綠藍）反上來的補光，只在字的下緣 |
| 品牌 F | `#00a0e9` → `#0068b7` | 不變（`logo3BlueA/B`） |

不能出現 R=G=B 的中性灰；最亮的白只留給太陽高光與 1–2px 的邊。

## 光（與開場世界同一套，會由 CONFIG 給）
- **主光＝開場太陽**：畫面左上，方位約 −18°（往交接時跟著山谷太陽走到 −32°）、仰角約 11°；顏色 `#ffdcb8`。
  讀 `CONFIG.openingWorld.sunAzimuth / sunElevation / sunColor`（world 方向：方位 0＝−Z 正前方，負值往左，跟 ALPINE_LIGHT 同定義），
  或直接沿用房間的 `palette`（`CONFIG.field`，已換成山谷色）＋ 房間光核方向。
- **補光＝天空**：上方來的冷藍（`#3b74b9` 系），強度約主光的 35–45%。
- **反光＝湖面**：下方 `#4d7f8c`，很弱（≈15%），讓字底不死黑。
- 明暗分配：太陽側（左、上緣）暖、亮；背光側（右、下內壁）冷藍、暗。這個「暖邊／冷影」就是山谷岩壁那套分光。

## 材質感
- **清透優先**：clear 約 .75–.85，看得到後面的天與遠山被折射（bend 維持約 1.1–1.2，不要更誇張）。
- **厚度吸收**：越厚越藍（往 `#0f3a6e`），薄邊幾乎無色——這是「融水」和「玻璃」的差別。
- **霜只在瞬間**：成字鎖定那一下可以有霜／閃（lockFlash），之後退掉；靜止時 frost ≤ .12、needles ≤ .3、sparkle ≤ .2。
- **虹彩**：≤ .01（山谷裡沒有彩虹色薄膜），iridPatch 0。
- **表面**：極淡的水紋（normalScale 小），反射帶要連續、乾淨，像一條鈷藍到霧白的漸層，而不是碎花。
- **邊**：倒角邊抓太陽的暖金線（rim `#ffc690`），另一側的倒角是深藍墨線（`#13233c`），字才有「塊」感。

## 明度目標（L*，在 1440×900 截圖量）
- 字體平均 L* 約 55–70（背景天空 45–80，要能分出來）；暖邊 ≥ 90；深芯 25–35。
- 字不得比太陽針點亮；bloom 不要把字洗成一片白。

## 參數方向（給實作參考，不是硬性數值）
- `logoLetters`：tint `#e3eef9`、ink `#163f73`、frost ≤ .12、clear .8、glow .35（暖）、sheen .5、rimLight 1.2、sparkle ≤ .2、needles ≤ .3、tone ≈ .85。
- `logoGlass`：tint `#d9e9f7`、shadeColor `#1b3352`、sssColor `#bfe0f5`、iridescence ≤ .01、iridPatch 0、sunSpec ≈ .9（暖色 `#ffdcb8`）、envSky ↑、envStudio ↓、reflectionStrength ≈ 1.2、frost/cloud/bubble 0。
- 色彩一律寫成 sRGB hex，讓參數面板可以調。

## 不要
- 霜白、奶白、灰玻璃（舊棚景的感覺）。
- 紫／粉虹彩。
- 太陽在右側或正後方的打光（開場世界的太陽在左上）。
- 改到成字動畫、水珠、散開的特效時序（不在範圍內）。
