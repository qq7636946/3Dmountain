# 1-6 獨立版本

對外入口：../../1-6.html

- 本資料夾擁有 1-6 使用的 JS、CSS、字型、圖片、模型與影片副本。
- 頁面程式：prototypes/index1-6/js/；樣式：prototypes/index1-6/*.css。

- Three.js、OGL 與 Google Fonts 保留原有外部套件網址。
